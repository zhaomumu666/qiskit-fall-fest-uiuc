# Qiskit Fall Fest @ UIUC

## From Code to Qubit

An open-source quantum computing outreach event designed to introduce students to the full quantum computing stack.

Rather than teaching quantum computing as a collection of disconnected concepts, this event follows a quantum program from:

Python
→ Qiskit
→ Quantum Circuits
→ Compilation
→ Quantum Hardware
→ Qubits

## Event

**Date:** Tentatively October 24, 2026  
**Time:** Tentatively 9:00 AM – 5:00 PM  
**Location:** Tentatively MSEB 305, University of Illinois Urbana-Champaign

## Program

### Session 1 — The Quantum Story

Why quantum computing exists and how the field developed.

### Session 2 — Your First Quantum Program

Learn to create quantum circuits using Python and Qiskit.

### Session 3 — From Circuit to Hardware

Follow a quantum program through compilation, control systems, and physical quantum hardware.

### Session 4 — IBM Quantum Guest Session

A guest speaker from IBM Quantum will discuss quantum computing in practice.

## Challenge

### Build a Quantum Computer Challenge

Participants design a realistic quantum computing architecture by considering:

- Qubit technology
- Hardware architecture
- Control systems
- Error correction
- Software stack
- Scalability
